# БлагоСервис — от заявки до оплаты

Коммерческая HTML-презентация, 17 слайдов. Данные и проверка интерфейсов:
**16 октября 2026**, Europe/Moscow.

## Открыть

Откройте [`index.html`](index.html) двойным щелчком в современном браузере.
HTML автономный: изображения, стили и навигация находятся внутри файла,
интернет и вход в сервисы для просмотра не нужны.

- Стрелки ← / → или кнопки внизу — переключение слайдов.
- «Содержание» — переход к нужной теме.
- Нажатие на скриншот — увеличение, Escape — закрыть.
- F или «Полный экран» — режим показа.
- Три вкладки на слайде писем — разные примеры и их польза.
- «PDF / Печать» — экспорт из браузера. Готовая версия: `presentation.pdf`.
- На телефоне презентацию можно листать вертикально.

PDF содержит дополнительные страницы с напоминанием и благодарностью, чтобы
интерактивные примеры писем также были доступны при пересылке PDF.

## Содержание

Заявка → чат → отчёт водителя → подтверждения → касса → работы → счёт →
задача Bitrix24 → письма и оплата → кабинет клиента → контроль исключений.
В конце — предложенный сценарий пилота и показатели для проверки эффекта.

Скриншоты кабинетов и карты сняты в рабочей системе в режиме чтения.
Скриншоты чатов, кассы и Bitrix24 предоставлены пользователем.
Письма — сокращённые обезличенные HTML-макеты на основе предоставленных писем,
а не скриншоты почты. Настоящие email, банковские ссылки, пароли и cookies
не включены в материалы; размытые адреса в макетах фиктивные.

Сведения об источниках, периодах и ограничениях: [`SOURCES.md`](SOURCES.md).
Проверка связки сервисов: [`../service-review-2026-10-16.md`](../service-review-2026-10-16.md).

Материалы содержат реальные суммы и клиентские примеры для коммерческого
показа. Публичная публикация и загрузка на production не выполнялись.
